# Разработка и проверка калькулятора сдачи вторсырья

Заготовка раздела научной работы. Транспортное исследование остаётся отдельной частью; калькулятор связывает транспорт и отходы через расходы на доставку вторсырья.

## 1. Задача программы
«EcoEsep: калькулятор накопления и сдачи вторсырья в Көкшетау» помогает семье или школьному классу выбрать вариант сдачи вторсырья с учётом массы, цен приёма и затрат на топливо. Программа сравнивает денежный результат и дополнительный пробег; она **не** определяет «самый экологичный способ» — для этого нужен отдельный анализ.

## 2. Исходные данные
- Пункты приёма: название, адрес, материалы, цены, минимальная партия, требования, дата проверки, источник (см. `docs/data-collection.md`).
- Ввод пользователя: кто собирает, масса по материалам, способ доставки, расход и цена топлива, дополнительный пробег.

## 3. Формулы и допущения
- Выручка: R = Σ mᵢ·pᵢ — только материалы, которые пункт принимает и цена которых известна.
- Расход топлива: Q = d·c/100.
- Расходы на топливо: C = Q·p_топл.
- Результат после расходов на топливо: B = R − C (не чистая прибыль).
- Порог накопления: m_min = max(C/p; минимальная партия); при p = 0 порог не определён.
- Отдельная поездка: d = 2 × расстояние в одну сторону; заезд по пути: d = прибавка к маршруту; пешком: C = 0 (время не учитывается).

## 4. Алгоритм сравнения пунктов
1. Для каждого пункта разделить материалы: принимаются / цена уточняется / ниже партии / не принимаются.
2. Посчитать R, d, Q, C, B.
3. Отсортировать по B. «Лучший для всего набора» выбирается только среди пунктов, принимающих все материалы.
4. Для выбранного пункта вывести порог накопления и совет «сдать сейчас или накопить».
5. Для группы — сравнить сумму отдельных поездок с одной общей (пробег общей поездки вводится с учётом объезда).

## 8. Ограничения
- Цены приёма меняются; у каждого пункта указывается дата проверки.
- Расход топлива приблизительный.
- Время, обслуживание автомобиля и другие расходы не учитываются.
- Программа охватывает только введённые и проверенные пункты.
- Пилотная выборка не репрезентативна для города.
