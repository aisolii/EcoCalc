# Сбор данных о пунктах приёма

Начните с 2–3 пунктов, а не со всего города. Если цену не удалось подтвердить — не придумывайте её: оставьте поле цены пустым («уточняется»).
Сохраняйте подтверждения: скриншоты прайсов, записи разговоров, фото объявлений (с разрешения владельца).

## Как внести в калькулятор

1. В блоке «Г» нажмите «Изменить» у условного пункта или «+ пункт».
2. Отметьте принимаемые материалы, впишите цены и минимальные партии.
3. Укажите дату проверки и источник; отметьте «Цены подтверждены», только если цена получена от пункта.
4. «Экспорт данных» сохраняет пункты в JSON — этот файл можно передать одноклассникам («Импорт»).

Либо отредактируйте `js/data.js` — тогда данные увидят все, кто открывает сайт.
