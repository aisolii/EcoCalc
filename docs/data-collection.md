# Қабылдау пункттері туралы деректер жинау

Бүкіл қаладан емес, 2–3 пункттен бастаңыз. Бағаны растау мүмкін болмаса, оны ойдан шығармаңыз: баға өрісін бос қалдырыңыз («нақтыланбаған»).
Растайтын құжаттарды сақтаңыз: прайстардың скриншоттары, әңгімелердің жазбалары, хабарландырулардың фотосуреттері (иесінің рұқсатымен).

## Калькуляторға енгізу

1. 4-бөлімде шартты пункттің «Өзгерту» батырмасын немесе «+ пункт қосу» батырмасын басыңыз.
2. Қабылданатын материалдарды белгілеп, бағалар мен ең аз партияларды жазыңыз.
3. Тексерілген күнін және дереккөзді көрсетіңіз. «Бағаларды пункт растады» белгісін баға пункттің өзінен алынғанда ғана қойыңыз.
4. «Пункттерді экспорттау» пункттерді JSON файлына сақтайды — оны сыныптастарға беруге болады («Импорттау»).

Немесе `js/data.js` файлын өңдеңіз — сонда деректерді сайтты ашқандардың бәрі көреді.
