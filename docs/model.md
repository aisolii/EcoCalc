# Қайталама шикізатты жинау және өткізудің математикалық моделі

Бұл құжат ғылыми жұмыстың «Математикалық модель» бөліміне арналған. Барлық формулалар сайттағы «Математикалық модель» бетінде іске асырылған (`js/model.js`) және автоматты тесттермен тексерілген (`tests/model.test.js`).

## 0. Белгілеулер

| Белгі | Мағынасы | Бірлігі |
|---|---|---|
| m(t) | үйде жиналған шикізат массасы | кг |
| g, g(t) | шикізаттың пайда болу жылдамдығы | кг/күн |
| M | сақтау орнының сыйымдылығы | кг |
| p̄ | 1 кг жиналған шикізаттың орташа бағасы (R / m) | ₸/кг |
| C | бір сапардың жанармай шығыны, C = d·c·p_ж / 100 | ₸ |
| T | өткізу аралығы (екі сапар арасы) | күн |
| J(T) | бір күнге шаққандағы орташа нәтиже | ₸/күн |

## 1. Жинақталу моделі (дифференциалдық теңдеу)

**Жорамал.** Шикізат g жылдамдықпен пайда болады. Сақтау орны бос болғанда оның бәрі сақталады; толған сайын (m → M) адамдар шикізаттың көбін жалпы қоқысқа тастайды. Сақталатын үлес 1 − m/M деп алынады:

  dm/dt = g · (1 − m/M),  m(0) = m₀.

Қоқысқа кету ағыны: dL/dt = g · m/M. Сақталу заңы: m(t) + L(t) = m₀ + g·t.

**Аналитикалық шешім (g = const).** Айнымалыларды бөлеміз:

  dm / (M − m) = (g/M) dt ⇒ −ln(M − m) = (g/M)·t + const ⇒

  **m(t) = M − (M − m₀)·e^(−g·t/M).**

Берілген m* массаға жету уақыты (m* < M):

  **t* = −(M/g) · ln((M − m*) / (M − m₀)).**

m* ≥ M болса, t* = ∞: сақтау орны тым кіші, бұл массаға ешқашан жетпейді. M → ∞ болғанда m(t) = m₀ + g·t (сызықтық өсу) — модель қарапайым жағдайды өз ішіне алады.

**Маусымдық жағдай.** g(t) = g₀ · (1 + A·cos(2π(t − t_max)/365)), мұнда A — маусымдық ауытқу, t_max — шикізат ең көп жиналатын күн. Бұл теңдеу Рунге–Кутта 4-ретті әдісімен h = 0,25 күн қадаммен сандық шешіледі:

  k₁ = f(tₙ, yₙ), k₂ = f(tₙ + h/2, yₙ + h·k₁/2), k₃ = f(tₙ + h/2, yₙ + h·k₂/2), k₄ = f(tₙ + h, yₙ + h·k₃),
  yₙ₊₁ = yₙ + h·(k₁ + 2k₂ + 2k₃ + k₄)/6.

**Тексеру.** A = 0 болғанда сандық және аналитикалық шешімдер 10⁻⁶ кг дәлдікпен сәйкес келеді (тест М1).

## 2. Оңтайлы өткізу аралығы (оңтайландыру)

Шикізатты әр T күн сайын өткізсек, бір циклдің нәтижесі p̄·m(T) − C. Бір күнге шаққанда:

  **J(T) = (p̄ · m(T) − C) / T → max,  T ∈ [1; 365],  m(T) ≥ m_партия.**

Бұл жерде екі қарама-қарсы әсер бар: жиі өткізсек, жанармай шығыны C/T үлкен; сирек өткізсек, сақтау орны толып, шикізат жоғалады (m(T) өспейді, бірақ T өседі).

**Қажетті шарт** (g = const, m₀ = 0, a = g/M):

  J'(T) = [p̄·m'(T)·T − (p̄·m(T) − C)] / T² = 0 ⇒

  **p̄·g·T·e^(−aT) = p̄·M·(1 − e^(−aT)) − C.**

Бұл трансцендентті теңдеу, оны элементар функциялармен шешу мүмкін емес, сондықтан максимум 0,25 күн қадамды торда сандық ізделеді (m(T) — Рунге–Кутта әдісімен). Тест М2 табылған T* осы шартты қанағаттандыратынын тексереді.

**Шекті жағдайлар.**
- M → ∞: J(T) = p̄·g − C/T монотонды өседі, яғни оңтайлы T тек сақтау орнымен шектеледі.
- C = 0 (жаяу): J(T) кемиді — жиі өткізген тиімді (уақыт есепке алынбайды).

**Экологиялық көрсеткіш.** Өткізілетін шикізат үлесі η(T) = m(T) / (g·T). g = const үшін η(T) = (1 − e^(−aT)) / (aT). Ол сақтау орнының шектеулілігі қанша шикізатты полигонға жіберетінін көрсетеді.

## 3. Тәуекел: Монте-Карло әдісі

Бағалар расталмаған, отын шығыны мен маршрут өзгереді, сондықтан бір сапардың нәтижесі — кездейсоқ шама:

  B = R₀ · k_p · k_m − d · c · p_ж / 100.

| Шама | Үлестірім | Әдепкі ауытқу |
|---|---|---|
| k_p — баға коэффициенті | үшбұрышты [1 − s; 1; 1 + s] | расталмаған ±25 %, расталған ±5 % |
| k_m — таразы қателігі | қалыпты N(1; s) | 3 % |
| d — қашықтық | қалыпты N(d; s·d) | 10 % |
| c — отын шығыны | үшбұрышты [c(1 − s/2); c; c(1 + s)] | 15 % (қалада көбірек) |
| p_ж — жанармай бағасы | қалыпты N(p; s·p) | 2 % |

Қалыпты шамалар Бокс–Мюллер түрлендіруімен, үшбұрышты шамалар кері үлестірім функциясы әдісімен алынады. Кездейсоқ сандар генераторы (mulberry32) seed = 42 арқылы бекітілген, сондықтан эксперимент қайталанады.

Нәтижелер (N = 10 000 сынақ):
- ақталу ықтималдығы P(B > 0) ≈ (оң нәтижелер саны) / N, стандартты қатесі σ_P = √(P(1 − P)/N);
- 5 %, 50 %, 95 % квантильдер, орташа мән және стандартты ауытқу;
- сезімталдық: әр фактор мен B арасындағы Пирсон корреляциясы r, үлесі r² / Σr².

Тексеру: ауытқулар нөлге тең болғанда нәтиже детерминистік есеппен дәл сәйкес келеді; номиналда R = C болғанда P ≈ 0,5 (тест М3).

## 4. Болжам: ең кіші квадраттар әдісі

Жинау күнделігіндегі өлшемдер (tᵢ, mᵢ) бойынша m(t) = g·t + b:

  g = Σ(tᵢ − t̄)(mᵢ − m̄) / Σ(tᵢ − t̄)²,  b = m̄ − g·t̄,

  R² = 1 − Σ(mᵢ − m̂ᵢ)² / Σ(mᵢ − m̄)²,

  σ_g = √( Σ(mᵢ − m̂ᵢ)² / (n − 2) / Σ(tᵢ − t̄)² ),  95 % сенім аралығы: g ± t₀,₉₇₅;ₙ₋₂ · σ_g.

Табылған g 1–2-бөлімдерге беріледі. Сызықтық модель сақтау орны толмаған бастапқы кезеңде дұрыс (m ≪ M болғанда 1 − m/M ≈ 1, яғни ДТ шешімі сызықтыққа жуықтайды).

## 5. Өткізу жоспары: дискретті оңтайландыру

Пункттер жиыны J, материалдар I, mᵢ — масса, pᵢⱼ — j пункттегі баға, Cⱼ — j пунктке сапар шығыны. S ⊆ J пункттерін таңдап, әр материалды S ішіндегі ең жоғары бағалы пунктке береміз:

  **B(S) = Σᵢ mᵢ · max_{j∈S} pᵢⱼ − Σ_{j∈S} Cⱼ → max.**

Бұл — сыйымдылығы шектелмеген орналастыру есебі (uncapacitated facility location problem), жалпы жағдайда NP-қиын. Көкшетауда пункт аз (n ≤ 12), сондықтан 2ⁿ − 1 ішкі жиынның бәрі толық іріктеледі және табылған шешім кепілді түрде оңтайлы. Ең аз партиядан кем материал ол пунктке берілмейді. Жорамал: әр пунктке бөлек сапар (шығынның жоғарғы бағасы).

## 5а. Мектеп акциясы: деректерге негізделген модель (`js/campaign.js`)

**Регрессия және сынып болжамы.** Әр отбасы i: mᵢ(t) = bᵢ + gᵢ·t (ЕКК). Сынып: M(T) = Σᵢ(bᵢ + gᵢT). Отбасылардың қателері тәуелсіз деп,

  Var M̂(T) = Σᵢ sᵢ²·(1 + 1/nᵢ + (T − t̄ᵢ)²/Sₜₜ,ᵢ),  95 % болжам аралығы: M̂ ± 1,96·√Var.

Бір ғана өлшемі бар отбасыға медианалық жылдамдық беріледі (pooling).

**Тексеру (hold-out).** Әр отбасының соңғы өлшемі модельге қосылмай, кейін болжаммен салыстырылады; салыстыру базасы — аңғал модель «масса өзгермейді».

**Жинау күнін оңтайландыру.** mⱼ(T) = sⱼ·M(T) (sⱼ — материал үлесі),

  B(T) = Σⱼ mⱼ(T)·pⱼ(mⱼ(T)) − ⌈M(T)/Q⌉·C_сапар → max, T ≤ T_мерзім,

pⱼ(m) — сатылы функция, ⌈·⌉ — бүтін бөлік. B(T) үзілісті, сондықтан күн сайынғы дискретті іріктеу қолданылады. Қосымша талдау: сатыға жетпесе, Δm = m_саты − mⱼ(T*) және түсім өсімі ΔR есептеледі.

**Маршрут.** Түзу арақашықтық — гаверсинус; жол d = k·s, k = Σsᵢrᵢ/Σsᵢ² (бас нүкте арқылы өтетін ЕКК). Ашық коммивояжер есебі (мектеп → нүктелер → пункт) Хелд–Карп әдісімен дәл шешіледі:

  D(S, j) = min_{i∈S∖{j}} [D(S∖{j}, i) + d(i, j)], күрделілігі O(n²·2ⁿ).

Салыстыру: әр отбасы өз нүктесінен пунктке жеке барып-қайтса, Σ 2·d(нүктеᵢ, пункт). CO₂ = 2,35 кг × литр (US EPA).

## 6. Модельдің шектеулері

- 1 − m/M түріндегі жоғалу заңы — қарапайым жорамал; оның параметрін (M) нақты бақылаумен тексеру керек.
- p̄ қазіргі материалдар арақатынасы сақталады деп есептеледі.
- Монте-Карлодағы үлестірімдер мен ауытқулар — сараптамалық бағалар; оларды пилоттық тексеру деректерімен нақтылауға болады.
- Уақыт, көлікке қызмет көрсету шығындары есепке алынбайды.

## 7. Әрі қарай дамыту

- Пилоттық журнал деректері бойынша M және ауытқу параметрлерін бағалау (параметрлерді идентификациялау).
- Пункттер арасындағы қашықтықтар белгілі болса — бір сапарда бірнеше пунктке соғу (коммивояжер есебі).
- Бірнеше отбасының ортақ сапарын жоспарлау (маршруттау есебі).
