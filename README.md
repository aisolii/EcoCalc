# EcoEsep — калькулятор накопления и сдачи вторсырья в Көкшетау

Помогает семье или школьному классу выбрать вариант сдачи вторсырья с учётом массы, цен приёма и затрат на топливо.

**Что умеет**
- **Сравнение пунктов** — выручка, пробег, топливо и «результат после расходов на топливо»; отдельно показывает, что пункт не примет.
- **Порог накопления** — сколько материала нужно, чтобы выручка покрыла топливо (с учётом минимальной партии).
- **Совместная сдача** — несколько отдельных поездок против одной общей с объездом для сбора.

## Запуск
Статический сайт без сборки: откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → ветка, папка `/`).
Данные, введённые пользователем, хранятся только в его браузере (localStorage).

## Структура
- `js/calc.js` — формулы и сравнение (чистые функции).
- `js/data.js` — материалы и пункты приёма. **Сейчас пункты условные** — замените проверенными данными.
- `js/app.js`, `index.html`, `css/style.css` — интерфейс.
- `tests/calc.test.js` — автоматические проверки: `node --test`.
- `docs/` — таблица тестов, шаблоны сбора данных и пилотной проверки, заготовка раздела работы.
