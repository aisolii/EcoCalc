# EcoEsep — Көкшетауда қайталама шикізатты жинау және өткізу калькуляторы

Отбасына немесе мектеп сыныбына шикізаттың массасын, қабылдау бағасын және жанармай шығынын ескере отырып, қайталама шикізатты өткізу нұсқасын таңдауға көмектеседі.

**Мүмкіндіктері**
- **Пункттерді салыстыру** — түсім, жүріс, жанармай және «жанармай шығынын шегергендегі нәтиже»; пункт нені қабылдамайтыны бөлек көрсетіледі.
- **Жинақтау шегі** — түсім жанармайды өтеу үшін қанша материал керек (ең аз партияны ескере отырып) және өтелу графигі.
- **Бірлесіп өткізу** — бірнеше жеке сапар мен айналып өтетін бір ортақ сапарды салыстыру.
- **Пилоттық тексеру журналы** — болжам мен нақты төлемді салыстыру, MAE және MAPE, CSV экспорты.
- **Есептеу хаттамасы** — нәтижелерді басып шығару немесе PDF-ке сақтау.

## Іске қосу
Жинауды қажет етпейтін статикалық сайт: `index.html` файлын браузерде ашыңыз немесе GitHub Pages қосыңыз (Settings → Pages → тармақ, `/` бумасы).
Пайдаланушы енгізген деректер тек оның браузерінде сақталады (localStorage).

## Құрылымы
- `js/calc.js` — формулалар мен салыстыру (таза функциялар, DOM-сыз).
- `js/data.js` — материалдар, қабылдау пункттері, жоба туралы мәлімет. **Қазір пункттер шартты** — тексерілген деректермен ауыстырыңыз.
- `js/format.js`, `js/store.js`, `js/chart.js`, `js/app.js`, `index.html`, `css/style.css` — интерфейс.
- `tests/calc.test.js` — автоматты тексерулер: `node --test`.
- `docs/` — тесттер кестесі, деректер жинау және пилоттық тексеру үлгілері, ғылыми жұмыс бөлімінің дайындамасы.
