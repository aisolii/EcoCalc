Калькулятор помогает семье или школьному классу выбрать вариант сдачи с учётом массы, цен приёма и затрат на топливо. Он сравнивает денежный результат и дополнительный пробег — но не оценивает, какой способ «самый экологичный».

Результат 1

Сравнение пунктов

Пункт, принимающий только часть сырья, не считается лучшим вариантом для всего набора. Отрицательный итог показывается как есть.

Результат 2

Сдать сейчас или накопить?

Порог накопления mmin = C / p — масса, при которой выручка покрывает топливо. Если у пункта есть минимальная партия, порог не меньше неё.

Результат 3

Объединиться

Несколько отдельных поездок против одной общей. Общая поездка не равна маршруту одной семьи — объезд для сбора сырья вводится отдельно.

Методика

Как считали

Формулы

Выручка
R = Σ mi · pi — только принимаемые материалы с известной ценой
Расход топлива
Q = d · c / 100 — d, км; c, л/100 км
Расходы на топливо
C = Q · pтопл
Результат после расходов на топливо
B = R − C — не чистая прибыль
Порог накопления
mmin = max(C / p, партия)

Ограничения

  • Цены приёма меняются — у каждого пункта указана дата проверки.
  • Расход топлива приблизительный: пробки, прогрев и стиль езды не учтены.
  • Время, обслуживание автомобиля и другие расходы не учитываются.
  • Программа охватывает только введённые и проверенные пункты.
